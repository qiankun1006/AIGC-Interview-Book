## AI Agent & 大模型应用

### Agent 架构与设计
- Agent 的规划能力怎么实现的？Plan-and-Execute 和 ReAct 各有什么适用场景？
- 多 Agent 协作时，Agent 之间怎么通信？消息格式怎么设计？
- Agent 的短期记忆和长期记忆分别怎么实现？
- 如何设计一个可插拔的 Tool 注册机制？
- Agent 执行过程中如果陷入死循环（反复调用同一个 Tool），怎么检测和中断？
- 如何给 Agent 设置执行超时和步数上限？
- 多个 Agent 并行执行时，结果如何汇总和冲突消解？

### Tool 调用与 MCP
- Tool 的输入参数校验怎么做？参数缺失或格式错误时怎么反馈给模型？
- Tool 返回结果太大（比如查数据库返回几万行），怎么处理？
- 同一个功能有多个 Tool 都能完成，Agent 怎么选最优的？
- MCP 协议下，Tool 的动态发现和热加载怎么实现？
- Tool 调用是同步还是异步？异步情况下怎么把结果回传给 Agent？
- 如何对 Tool 做权限控制？不同用户能看到不同的 Tool 吗？

### RAG 与知识库
- 文档切分策略怎么选？固定长度切分 vs 语义切分各有什么优缺点？
- 多路召回（向量召回 + 关键词召回）怎么融合排序？
- 知识库更新后，向量索引怎么增量更新而不影响线上服务？
- 用户问题很短、很模糊时，怎么提高召回准确率？（Query Rewriting / HyDE）
- 图表、表格类文档怎么处理？用什么解析策略？
- 如何处理文档中的层级结构（标题、子标题、段落）来提升检索效果？
- 多模态 RAG（图文混合检索）怎么实现？

### 模型调用与优化
- 调用大模型时遇到过哪些幻觉问题？怎么缓解？
- 模型输出的格式不稳定（要求 JSON 但偶尔返回纯文本），怎么兜底？
- 如何做模型降级？主模型挂了怎么自动切备用模型？
- Function Calling 和 Prompt 驱动 Tool 调用各有什么优劣？
- 流式输出（SSE）中断了怎么恢复？怎么保证用户体验？
- 如何设计 Prompt 版本管理和 A/B 测试？

### 评估与质量保障
- Agent 输出的评估怎么做？自动化评估 + 人工评估怎么结合？
- 如何构建评估数据集？Badcase 怎么持续沉淀和回归？
- RAG 的端到端评估指标有哪些？（Faithfulness、Answer Relevance、Context Recall）
- 线上 Agent 出错了怎么快速定位是哪个环节的问题（检索、推理、Tool 调用）？
- 有没有做用户反馈闭环？用户点踩后怎么自动分析原因？

### 性能与稳定性
- Agent 一次完整调用的链路耗时怎么分布？瓶颈在哪？
- 如何做 Token 预算管理？怎么在保证效果的前提下压缩上下文？
- 上下文窗口不够用时，有哪些压缩策略？（摘要、滑动窗口、关键信息提取）
- 大模型调用如何做限流和排队？
- 缓存策略怎么设计？相同或相似问题怎么命中缓存？
- 如何做灰度发布？新 Prompt 或新模型怎么逐步放量？
