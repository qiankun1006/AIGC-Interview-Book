# 二维 DP 不对称循环顺序总结

> 适用场景：两个维度含义不同（如字符串 s 和 t、字符串和模式串），循环方向、起点、是否需要单独初始化边界各不相同。

---

## 通用分析框架

### 第一步：写出转移方程，看每个维度的依赖方向

| 依赖的是 | 循环方向 |
|---------|---------|
| `dp[i+1][...]` | i 从大到小 |
| `dp[i-1][...]` | i 从小到大 |
| `dp[...][j-1]` | j 从小到大 |
| `dp[...][j+1]` | j 从大到小 |

### 第二步：确定谁在外层

> **核心原则：外层变量推进一步，内层所有依赖必须已经就绪。**

- 固定外层变量，检查内层变量扫描过程中，所需的"另一个维度"是否已全部算好
- 外层变量 = 你依赖的那个"已完成的整行或整列"

### 第三步：确定起点和终点

- 从有效区域的边界出发（i <= j？ i >= 1？）
- 看是否需要在双重循环之前单独初始化边界行/列（dp[0][j] 或 dp[i][0]）

## 题目汇总

### LeetCode 10 — 正则表达式匹配

**dp 定义：**
```
dp[i][j]：s 的前 i 个字符能否被 p 的前 j 个字符匹配
```

**转移方程：**
```
p[j] == '*':
    dp[i][j] = dp[i][j-2]                                    // * 匹配 0 次
             || (dp[i-1][j] && (s[i]==p[j-1] || p[j-1]=='.')) // * 再匹配一个

p[j] 是普通字符或 '.':
    dp[i][j] = dp[i-1][j-1] && (p[j]=='.' || s[i]==p[j])
```

**不对称分析：**
- i 依赖 `i-1` → i 从小到大
- j 在 `*` 分支依赖 `j-2`（向左跳两格）和 `j` 自身（同行），不依赖 `j-1` 整体方向
- i 在外层：每轮外层推进，`i-1` 行已全部就绪 ✅

**边界初始化（关键！不能省）：**
```java
dp[0][0] = true; // 空串 vs 空串

// 第 0 行：空串 s 能被 p 的前 j 个字符匹配
// 只有 p[j]=='*' 时才能消掉一对 x*，步长为 2
for (int j = 2; j < n; j += 2)
    dp[0][j] = dp[0][j-2] && p.charAt(j) == '*';
```

> 为什么第0行不能在双重循环里顺带处理？
> 因为循环从 `i=1` 开始，`i=0` 这行的状态完全取决于 p 中 `*` 的位置，逻辑独立，必须单独填。

**循环结构：**
```java
for (int i = 1; i < m; i++)        // i 从小到大，在外层
    for (int j = 1; j < n; j++)    // j 从小到大，在内层
```

### LeetCode 97 — 交错字符串

**dp 定义：**
```
dp[i][j]：s1 的前 i 个字符和 s2 的前 j 个字符，能否交错组成 s3 的前 i+j 个字符
```

**转移方程：**
```
c = s3[i+j-1]
dp[i][j] = (dp[i-1][j] && s1[i-1]==c)    // 这一步用 s1 的第 i 个字符
         || (dp[i][j-1] && s2[j-1]==c)    // 这一步用 s2 的第 j 个字符
```

**不对称分析：**
- i 依赖 `i-1` → i 从小到大
- j 依赖 `j-1` → j 从小到大
- 两个分支分别消耗 s1 和 s2 的不同字符，语义完全不对称
- i 在外层：`i-1` 行已全部就绪，`j-1` 在内层扫描时天然已算好 ✅

**边界初始化（关键！两条边都要初始化）：**
```java
dp[0][0] = true;

// 第一列：只用 s1 匹配 s3
for (int i = 1; i <= m; i++)
    dp[i][0] = dp[i-1][0] && s1.charAt(i-1) == s3.charAt(i-1);

// 第一行：只用 s2 匹配 s3
for (int j = 1; j <= n; j++)
    dp[0][j] = dp[0][j-1] && s2.charAt(j-1) == s3.charAt(j-1);
```

> 为什么两条边都要单独初始化？
> `dp[i][0]` 表示"只用 s1，不用 s2"的情况，转移方程的 s2 分支此时用不上，必须单独处理。`dp[0][j]` 同理。

**循环结构：**
```java
for (int i = 1; i <= m; i++)       // i 从小到大，在外层
    for (int j = 1; j <= n; j++)   // j 从小到大，在内层
```

### LeetCode 115 — 不同的子序列

**dp 定义：**
```
dp[i][j]：s 的前 i 个字符中，t 的前 j 个字符作为子序列出现的次数
```

**转移方程：**
```
s[i-1] == t[j-1]:
    dp[i][j] = dp[i-1][j]       // 不用 s[i-1] 匹配
             + dp[i-1][j-1]     // 用 s[i-1] 匹配 t[j-1]

s[i-1] != t[j-1]:
    dp[i][j] = dp[i-1][j]       // 只能跳过 s[i-1]
```

**不对称分析：**
- i 和 j 都依赖 `i-1` 行，j 无论相等还是不等都只依赖 `i-1`，不依赖 `i+1`
- 相等时额外依赖 `dp[i-1][j-1]`（斜上方），不等时只依赖正上方 `dp[i-1][j]`——这是不对称的核心
- i 在外层：`i-1` 行全部就绪 ✅

**边界初始化：**
```java
// 第一列：t 为空串时，s 的任意前缀都有且只有 1 种方案（什么都不选）
for (int i = 0; i <= m; i++)
    dp[i][0] = 1;
// 第一行 dp[0][j]（j>0）默认为 0：空串 s 无法包含非空 t，不需要额外设置
```

> 只需初始化一条边（第一列），另一条边（第一行）默认值 0 就是正确答案。
> 这是和 LeetCode 97 的区别：97 两条边都需要，115 只需要一条。

**循环结构：**
```java
for (int i = 1; i <= m; i++)       // i 从小到大，在外层
    for (int j = 1; j <= n; j++)   // j 从小到大，在内层
```

### LeetCode 131 — 分割回文串（预处理 DP）

**dp 定义：**
```
isPalin[i][j]：s[i..j] 是否是回文串（i 是左端点，j 是右端点）
```

**转移方程：**
```
isPalin[i][j] = (s[i] == s[j]) && (j-i <= 2 || isPalin[i+1][j-1])
```

**不对称分析：**
- i 依赖 `i+1` → **i 从大到小**（和前三道题相反！）
- j 依赖 `j-1` → j 从小到大
- 有效区域只在上三角（i <= j），下三角全是无效格
- i 在外层：每次外层推进，`i+1` 行已全部就绪 ✅

**边界初始化：**
```java
// 无需单独初始化！
// 单字符（i==j）和双字符（j-i==1）的情况由 j-i <= 2 这个条件直接覆盖
// isPalin 数组默认值 false 不影响正确性
```

> 这道题是唯一一个 i 从大到小、且不需要单独边界初始化的例子。
> 原因：`j-i <= 2` 这个短路条件把长度1和长度2的情况直接处理掉了。

**循环结构：**
```java
for (int i = n-1; i >= 0; i--)    // i 从大到小，在外层（依赖 i+1）
    for (int j = i; j < n; j++)   // j 从 i 开始（有效区域 i<=j），从小到大
```

## 横向对比

| 题目 | i 方向 | j 方向 | 谁在外层 | 需要初始化的边 | 有效区域 |
|-----|-------|-------|---------|-------------|---------|
| 10 正则匹配 | 小→大 | 小→大 | i | 第0行（逐步推导 `*`） | 全部 |
| 97 交错字符串 | 小→大 | 小→大 | i | 第一行 + 第一列 | 全部 |
| 115 不同子序列 | 小→大 | 小→大 | i | 第一列（=1） | 全部 |
| 131 回文预处理 | **大→小** | 小→大 | i | **无需初始化** | 上三角（i<=j）|

## 记忆口诀

```
1. 写转移方程，看 i 和 j 各自依赖"更大"还是"更小"
2. 外层变量 = 你依赖的那个"已完成的整行"
   （外层推进一步，内层所需的行/列已全部就绪）
3. 起点 = 有效区域的第一个格子
4. 看默认值够不够用：
   - 够用 → 不需要单独初始化（131）
   - 不够用 → 找出哪条边的状态无法从转移方程推出，单独填（10/97/115）
